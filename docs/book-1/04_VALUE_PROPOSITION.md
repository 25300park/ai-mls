## Value statement

AI MLS는 scattered candidate information을 provenance-aware internal intelligence로 바꾸고, AI assistance와 human verification을 결합해 staff가 더 적은 반복 작업으로 더 신뢰할 수 있는 shortlist를 제공하도록 한다.

## Business value

- staff capacity를 반복 검색/정리에서 client judgment와 relationship으로 이동
- source·candidate·viewing·closing 연결을 통한 channel/partnership 판단 개선
- verification/permission/audit control로 reputation과 unauthorized exposure risk 보호
- reusable property intelligence foundation으로 future product/network option 확보

## Customer value

- tenant/buyer에게 requirement에 맞고 현재성이 확인된 option 제공
- unknown, confidence, source와 condition을 숨기지 않는 clearer communication
- stale/duplicate misinformation과 반복 correction 감소
- restricted contact와 personal requirement의 privacy-aware 처리

## Operational value

- candidate를 한 번 capture하고 여러 workflow에서 재사용
- property/unit/offer/source를 구분한 비교와 duplicate review
- requirement 변경 시 structured re-search/rematch 지원
- verification, permission, proposal와 outcome의 handoff visibility
- exception/queue/KPI를 통한 manager oversight

## Competitive advantage

advantage는 “AI 사용” 자체가 아니라 다음 capability의 결합에서 나온다는 hypothesis다.

1. local workflow에 맞는 source-aware candidate discovery
2. property intelligence와 provenance의 장기 축적
3. human verification/permission이 포함된 trust workflow
4. client requirement에서 outcome까지의 feedback loop
5. internal-first evidence를 future cooperative network로 전환할 governance foundation

경쟁 우위 주장은 market/customer research로 검증해야 하며 독점성이나 우월성을 사실로 단정하지 않는다.

## Time savings

| Work | Saving mechanism | KPI |
|---|---|---|
| multi-source search | reusable candidate index와 requirement-based retrieval | search time |
| field extraction | AI-assisted draft + human correction | capture/review time |
| duplicate comparison | similarity suggestion + provenance-aware review | duplicate/rework rate |
| shortlist creation | explainable ranking과 saved requirement | time to shortlist |
| verification follow-up | status/freshness/owner visibility | verification turnaround |

target은 baseline 측정 후 정하며 human approval time을 제거 대상으로 보지 않는다.

## Quality improvements

- source linkage completeness
- verified-available/freshness rate
- duplicate precision과 false merge prevention
- permission/approval trace completeness
- client correction와 stale proposal 감소
- match relevance와 viewing conversion 개선

## Scalability

business scalability는 listing volume만이 아니라 staff당 처리 가능한 verified request, repeatable governance와 source/partner onboarding cost로 평가한다. architecture scaling 방식은 Book 2/9에서 결정한다.

## Future network value

`POST-MVP` broker network가 성립하면 contribution volume보다 다음 network quality가 중요하다.

- verified contributor identity/authority
- shared rule와 interoperable data
- update/correction/dispute accountability
- broader credible coverage와 faster cooperation
- governance-compliant analytics/benchmarking

## Value guardrails

- speed improvement가 `REQ-CONST-001`–`013`을 약화하면 value로 인정하지 않는다.
- revenue는 permission/privacy/source-policy를 우회하지 않는다.
- AI output volume을 business outcome으로 대체하지 않는다.
- [Success Metrics](09_SUCCESS_METRICS.md)의 paired quality/control KPI로 모든 value claim을 검증한다.
