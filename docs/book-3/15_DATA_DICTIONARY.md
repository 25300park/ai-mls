## Reading rules

- Primary Identifier는 logical opaque identifier 이름이며 SQL column/type 선언이 아니다.
- Retention은 승인된 exact period가 없으므로 trigger/class 수준으로 기록한다.
- Privacy 후보 class는 `PUBLIC_APPROVED`, `INTERNAL`, `CONFIDENTIAL_BUSINESS`, `RESTRICTED_PERSONAL`, `RESTRICTED_SECURITY`이며 Book 8에서 확정한다.
- Future expansion은 현재 구현 scope 또는 commitment가 아니다.

## Dictionary consistency rules

- Every implementation entity must map to this dictionary or an approved extension Decision/ADR.
- Entity name reuse with different authority is prohibited.
- Exact status vocabulary, physical type, nullability, uniqueness, index and deletion action require later schema review and must preserve these logical semantics.
- New personal/raw/AI-derived entity requires privacy and retention classification before approval.
