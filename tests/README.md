이 디렉터리는 승인된 technology stack 이후 test suite가 배치될 logical zone이다. Sprint 0에서는 production test code나 business fixture를 만들지 않는다.

현재 test evidence는 문서·구조·trace를 대상으로 하는 `TEST-056` dry review에 한정한다. test data에는 production personal data, credential 또는 raw third-party content를 사용하지 않는다.
